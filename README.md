# IT Expenditure Analysis

This Power BI dashboard compares IT actual spending with the plan and forecast across months, regions, business areas, IT areas, and cost groups. Its four pages—Budget Overview, Cost Drivers, Variance Explorer, and Data & Definitions—help identify where spending differs from plan and which areas need follow-up.

The report combines 93,729 rows from two sheets in the supplied Excel workbook. Full-year actual spending is **866.415 million** in source units, compared with a plan of **900.402 million**—a difference of **33.987 million below plan**. The forecast is **890.542 million**. Below-plan spending should be investigated before it is described as a saving.

Open `IT_Expenditure.pbix` in Power BI Desktop to explore the report. The source workbook is included as `IT_Expenditure_Source.xlsx`. The source does not specify a currency or year.
